# Brickwork API

> Brickwork (now part of DevHub) is an omnichannel retail platform that powers a digital presence for physical stores — store pages, store locators, appointments, in-store events with RSVPs, local services, and customer records. The Brickwork API v3 exposes admin management and public front-end store data. Admin endpoints authenticate with a company api_key query parameter.

## APIs
- [Brickwork API v3 (OpenAPI)](https://raw.githubusercontent.com/api-evangelist/brickwork/refs/heads/main/openapi/brickwork-openapi.yml): 107 operations across stores, appointments, events, RSVPs, services, customers, hours, and transactions.
